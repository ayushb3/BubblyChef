Bugs found 8 · 5 fixed, 3 filed

fixed

Recipe generation was returning HTTP 500 to every user

get_ai_manager was imported from the wrong module and awaited though it's synchronous. Both /v1/recipes/generate and /refine failed on every call, with the frontend wired straight to them. No test covered these routes.

fixed

Your setup guide couldn't produce a working install

The service reads BUBBLY_SUPABASE_SECRET_KEY; every doc and both .env.example files said BUBBLY_SUPABASE_SERVICE_ROLE_KEY. Production worked because its variable was set correctly by hand — anyone following the README got a service that couldn't authenticate.

fixed

Every build was red — and it wasn't your code

ruff>=0.4 was unbounded with no explicit rule set, so the linter's shifting defaults decided what CI enforced. Release 0.16 changed them and produced 140 errors against unchanged files. The rule set is now pinned in config.

fixed

Three more caught by strict typing

Saving any recipe raised AttributeError (tags vs dietary_tags). Expiring-items lookup raised TypeError — not_ is a property, not a method. And a count parameter still passed a string where an enum is now required.

fixed

A colour that was never defined

--color-coral is referenced six times with no fallback but declared nowhere, so favourited hearts and the Delete action quietly rendered in the wrong colour. One file had the fallback everyone else forgot — which is how we know the intended value.

filed

Duplicate ingredients over-deduct your pantry

A recipe listing onion twice deducts against full stock both times — the matcher never tracks what it has already consumed. Synonyms that normalise to one name hit this more easily than literal duplicates. Filed as issue #125.

filed

White text on the primary colour fails contrast in all five palettes

Measured between 1.35:1 and 1.87:1 where 4.5:1 is the accessible minimum. Visible on the Sign In button in the screenshots above — worst in Yuzu and Mint.

filed

Reduced-motion support exists but is never called

The helper in lib/motion.ts has zero call sites, so animations ignore the accessibility preference entirely. The active-theme ring in the theme picker is also white-on-near-white — effectively invisible in every palette.
