### Environment gotchas that will bite

- **`pip install -e ".[dev]"` fails** on `jstyleson` (old `setup.py`,
  `AttributeError: install_layout`). Install `setuptools<70` into the venv first.
- **Do not pipe installs through `tail`** — it masks the exit code, which is how
  the failure above went unnoticed for a while.
- System `python` and `pip` are mismatched; use the venv explicitly.
- `ruff` must stay `<0.16` (see #129) or lint fails on 144 pre-existing findings.

## 5. Things the docs got wrong

Corrected in this session, but worth knowing they were wrong recently:

- **Zustand is not a dependency.** `CLAUDE.md` listed it as the client-state
  library, which is why #122 was written assuming a Zustand store existed.
- **Next.js is 16.2.2**, not 14. `nextjs/AGENTS.md` says to read
  `node_modules/next/dist/docs/` before writing Next.js code — that is real, and
  the directory only exists after `npm ci`.
- **#5 and #8 were listed as open Phase 3 blockers.** Both are closed.
- `mypy --strict` is listed as a quality gate in `CLAUDE.md` but **is not in CI
  and does not pass** (73 errors, #128). It found a live production bug this
  session, so it is worth making real.
